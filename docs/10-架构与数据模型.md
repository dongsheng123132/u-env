## 2. 数据流

```
uenv scan
  └─> Registry::all() 得到 Vec<Box<dyn Detector>>
        └─> 逐个 detect(&ScanContext) -> DetectorResult
              └─> 汇总成 Environment（core 的顶层结构）
                    ├─> uenv-fingerprint: facts -> EnvironmentFingerprint
                    ├─> uenv-rules:       Environment -> Vec<Finding>
                    └─> uenv-report:      Environment + Findings -> md / json
```

**核心不变式**：`scan` 只产出事实（facts），**不做判断**。所有「这是个问题」的判断只发生在 `uenv-rules`。
detector 里不许写 severity，rule 里不许跑命令。违反这条，规则库就没法被外部贡献者扩展。

## 3. 核心数据结构（`uenv-core`）

全部 `#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]`，字段 `snake_case`。

```rust
/// scan 的顶层产物，也就是 environment.origin.json
pub struct Environment {
    pub spec: String,                    // 固定 "origin-environment/v0.1"
    pub generated_at: String,            // RFC3339，**不进指纹**
    pub uenv_version: String,            // CLI 版本，**不进指纹**
    pub identity: EnvironmentIdentity,
    pub detectors: BTreeMap<String, DetectorRecord>,  // key = detector id，BTreeMap 保证有序
    pub fingerprint: Option<EnvironmentFingerprint>,
}

pub struct EnvironmentIdentity {
    pub host_alias: String,              // 脱敏后的机器标识，默认 "<host>"
    pub os: OperatingSystem,
    pub architecture: Architecture,      // X64 | Arm64 | X86 | Unknown
    pub project: Option<ProjectManifest>,
}

pub struct OperatingSystem {
    pub family: String,                  // "windows"
    pub product_name: String,            // "Windows 11 家庭中文版"
    pub version: String,                 // "10.0.26100"
    pub build: u32,                      // 26100
    pub ubr: Option<u32>,                // Update Build Revision
    pub edition: Option<String>,
    pub display_version: Option<String>, // "24H2"
}

pub struct DetectorRecord {
    pub id: String,
    pub layer: Layer,                    // Host | Toolchain | Project
    pub title: String,
    pub status: DetectStatus,
    pub summary: String,
    pub facts: BTreeMap<String, FactValue>,     // ✅ 进指纹
    pub volatile: BTreeMap<String, FactValue>,  // ❌ 不进指纹
    pub evidence: Vec<Evidence>,                // ❌ 不进指纹
    pub elapsed_ms: u64,                        // ❌ 不进指纹
}

pub enum DetectStatus { Ok, Absent, Degraded, Error, Skipped }
pub enum Layer { Host, Toolchain, Project }

/// 有限的值类型 —— 不要用 serde_json::Value，规范化会失控
pub enum FactValue {
    Str(String),
    Int(i64),
    Bool(bool),
    Version(String),                     // 语义化字符串，原样保留
    Path(String),                        // 规范化规则见 §5
    List(Vec<FactValue>),                // 有序，规范化时**不排序**
    Set(Vec<FactValue>),                 // 无序，规范化时**排序去重**
    Map(BTreeMap<String, FactValue>),
}

pub struct Evidence {
    pub kind: EvidenceKind,              // Command | Registry | File | Env
    pub source: String,                  // 命令行 / 注册表路径 / 文件路径 / 变量名
    pub exit_code: Option<i32>,
    pub excerpt: String,                 // 截断到 2000 字符，已脱敏
}

pub struct ProjectManifest {
    pub root: String,
    pub kind: Vec<ProjectKind>,          // 一个项目可以同时是 Tauri + Node
    pub declared_toolchains: BTreeMap<String, String>,  // "node" -> ">=22"
    pub lockfiles: BTreeMap<String, String>,            // 文件名 -> sha256
    pub git: Option<GitState>,
}
pub enum ProjectKind { Tauri, Electron, Node, Rust, DotNet, WinUi, Python, Unknown }

/// rules 的产物
pub struct Finding {
    pub rule_id: String,                 // "rust.multiple-cargo-in-path"
    pub severity: Severity,              // Info | Warning | Error
    pub title: String,
    pub description: String,
    pub evidence: Vec<Evidence>,
    pub suggested_fix: Option<SuggestedFix>,
}
pub enum Severity { Info, Warning, Error }

pub struct SuggestedFix {
    pub safety: Safety,                  // Safe | Confirm | Manual
    pub explain: String,
    pub commands: Vec<String>,           // 要执行的
    pub rollback: Vec<String>,           // 撤销用的。commands 非空则 rollback 必须非空
    pub docs_url: Option<String>,
}
pub enum Safety { Safe, Confirm, Manual }

pub struct EnvironmentFingerprint {
    pub host: String,                    // origin-env:sha256:<64hex>
    pub toolchain: String,
    pub project: Option<String>,
    pub full: String,
}
```

**rule_id 命名**：`<域>.<短横线小写描述>`，例：`rust.multiple-cargo-in-path`、`windows.long-paths-disabled`、`fs.project-on-onedrive`。
**detector id 命名**：`<域>.<名词>`，例：`windows.version`、`toolchain.node`、`fs.project-location`。

## 4. Detector 契约（`uenv-scanner`）—— 外部贡献者的唯一入口

```rust
pub struct DetectorMeta {
    pub id: &'static str,
    pub layer: Layer,
    pub title: &'static str,
    pub cost: Cost,                      // Fast(<200ms) | Slow(>=200ms)
}

pub trait Detector: Send + Sync {
    fn meta(&self) -> DetectorMeta;
    /// 不适用时返回 false，会记为 Skipped。默认 true
    fn applicable(&self, _ctx: &ScanContext) -> bool { true }
    fn detect(&self, ctx: &ScanContext) -> DetectorResult;
}

pub struct DetectorResult {
    pub status: DetectStatus,
    pub summary: String,                 // 一句话，人读
    pub facts: BTreeMap<String, FactValue>,
    pub volatile: BTreeMap<String, FactValue>,
    pub evidence: Vec<Evidence>,
}
```

**硬规则**：
1. **一个 detector = 一个文件**：`crates/uenv-scanner/src/detectors/<id 用下划线>.rs`。跨文件共享逻辑放 `src/util/`。
2. **detect() 绝不 panic、绝不返回 Err**。任何失败 → `status: Error` + `summary` 写清原因 + evidence 留现场。一个 detector 挂掉不能让整次 scan 挂掉。
3. **只读**。不写文件、不改注册表、不改环境变量。
4. **必须留 evidence**：每条 fact 的来源（命令 / 注册表键 / 文件路径）都要能追溯，否则 diff 出来没人信。
5. **facts 里禁止出现**：绝对时间、耗时、PID、临时目录、随机端口、真实用户名/机器名（走脱敏）、可用磁盘字节数（波动大 → 放 volatile）。

### ScanContext

```rust
pub struct ScanContext {
    pub project_root: Option<PathBuf>,
    pub redact: bool,                    // 默认 true
    pub timeout: Duration,               // 默认 10s，单条命令
}

impl ScanContext {
    /// 唯一允许的外部命令调用入口。必须带超时、必须捕获退出码、
    /// 必须处理 GBK/UTF-16 输出（Windows 中文系统 chcp 936 是常态）
    pub fn run(&self, program: &str, args: &[&str]) -> CommandOutcome;
    /// 唯一允许的注册表读取入口（winreg 封装，失败返回 None 而不是 panic）
    pub fn reg_read(&self, hive: Hive, path: &str, name: &str) -> Option<RegValue>;
    /// PATH 里查同名可执行文件的**全部**命中（不是第一个）——冲突检测靠它
    pub fn which_all(&self, exe: &str) -> Vec<PathBuf>;
    /// 脱敏：把用户名/机器名/密钥样式串替换成占位符
    pub fn redact(&self, s: &str) -> String;
}

pub struct CommandOutcome {
    pub ran: bool,                       // 程序是否存在并启动
    pub exit_code: Option<i32>,
    pub stdout: String,                  // 已解码 + 已脱敏
    pub stderr: String,
    pub timed_out: bool,
    pub elapsed_ms: u64,
}
```

⚠️ **Windows 编码坑（必须处理，否则中文机器全乱码）**：子进程输出可能是 GBK(CP936)、UTF-8 或带 BOM 的 UTF-16LE。解码顺序：BOM → 尝试 UTF-8 → 回退当前 ANSI 代码页。解不出的字节用 U+FFFD，**不要 panic**。

### 注册表（registry）

`crates/uenv-scanner/src/registry.rs` 里一个显式函数：

```rust
pub fn all_detectors() -> Vec<Box<dyn Detector>> {
    vec![
        Box::new(detectors::windows_version::WindowsVersion),
        // 新 detector 在这里加一行
    ]
}
```

不用 `inventory`/`linkme` 之类的自动注册宏 —— 显式列表更好 review、更好排错，代价只是加一行。

## 5. 规范化与指纹（`uenv-fingerprint`）

指纹的全部意义是：**同一台机器的有效环境，跑两次必须得到同一个 hash**。任何抖动都会毁掉 diff 的可信度。

### 5.1 规范化规则

| 类型 | 规则 |
|---|---|
| `Str` | trim；连续空白折叠成一个空格；Unicode NFC |
| `Path` | 反斜杠 → 正斜杠；盘符大写（`c:/` → `C:/`）；去尾部 `/`；**其余部分保留大小写**（NTFS 不区分大小写但显示名有意义）；再走 `Str` 规则 |
| `Version` | 原样保留（`1.88.0` ≠ `1.88`，差异本身就是信息） |
| `Int`/`Bool` | 原样 |
| `List` | 保序 |
| `Set` | 先各自规范化，再按规范化后的 JSON 文本排序、去重 |
| `Map` | BTreeMap 天然有序；值为空的键**删除** |
| 空值 | `Str("")` / 空 `List` / 空 `Map` 一律从父级删除 |

### 5.2 canonical JSON

键排序（BTreeMap 自带）· 无多余空白 · UTF-8 无 BOM · 整数不带小数点 · 不允许浮点（有浮点需求就转成字符串）。

### 5.3 计算

```
host_input     = { detector_id: facts }  仅 layer == Host
toolchain_input= { detector_id: facts }  仅 layer == Toolchain
project_input  = { detector_id: facts }  仅 layer == Project（无项目则 None）
full_input     = { "host": <host_input>, "toolchain": ..., "project": ... }

<x> = "origin-env:sha256:" + hex_lower(sha256(canonical_json(<x>_input)))
```

短显示取 hex 前 12 位：`origin-env:sha256:8d04b9c2f1a3…`

⚠️ **status == Error 的 detector 不参与指纹**（否则网络抖动一次指纹就变）；但要在报告里显式列出「本次指纹缺少哪些 detector」，不能静默。

### 5.4 PATH 的特殊处理（关键设计）

PATH 原文随终端而变（Git Bash / PowerShell / cmd 各不同），**原文进 `volatile`**。
进 facts 的只有：**解析出的可执行文件绝对路径 + 版本**（`Set` 类型）。
这样「同一台机器换个终端跑」指纹不变，「真装了两个 Node」指纹一定变。

### 5.5 diff

`uenv diff a.json b.json` 按 detector → fact 键逐层比较，输出：

```
高风险差异（影响构建/运行）：
- toolchain.node: version  24.5.0 → 22.11.0
- toolchain.cargo: executables  1 处 → 2 处
低风险差异：
- windows.version: ubr  2454 → 2506
仅一侧存在：
- toolchain.webview2 (仅 A 有)
```

风险分级来自 `uenv-rules` 里注册的「关键 fact 键清单」，不是 diff 自己猜。

## 6. 规则引擎（`uenv-rules`）

第一版规则**用 Rust 写**（一个规则一个函数），YAML 规则 DSL 放到中线阶段。
理由：先用 20 条真实规则把需要的表达能力试出来，再设计 DSL，否则 DSL 一定设计错。

```rust
pub trait Rule: Send + Sync {
    fn id(&self) -> &'static str;
    fn evaluate(&self, env: &Environment) -> Vec<Finding>;
}
```

规则只读 `Environment`，**不许跑命令、不许读注册表**。跑不出来就说明 detector 缺 fact —— 那就去加 fact，不要在规则里绕过。

## 7. CLI 契约（`uenv-cli`）—— u-env 是「给 AI 用的本地 API」

### 7.1 输出分流（最重要的一条）

```
stdout = 结果数据（机器读）
stderr = 日志 / 进度 / 调试（人读）
```

绝不把日志混进 stdout。AI 调用 `uenv scan --json 2>/dev/null` 必须拿到纯净 JSON。

### 7.2 三种模式

| 场景 | 行为 |
|---|---|
| stdout 是 TTY（人在敲） | 可以有颜色、进度 |
| stdout 是管道（AI/脚本） | 纯文本，**绝不输出 ANSI / 进度条 / spinner** |
| `--json` | 强制 JSON，忽略 TTY |

TTY 检测：`std::io::IsTerminal`（std 1.70+，无需依赖）。

### 7.3 JSON 契约

```json
{ "ok": true, "data": {}, "error": null, "stats": { "elapsed_ms": 1234, "count": 21 } }
```

顶层必有 `ok`(bool)；失败时必有 `error`(string)；列表用数组不用拼接字符串；字段 `snake_case`；**数值不格式化**（字节给数字，不给 `"1.5MB"`）。

### 7.4 退出码

`0` 成功 · `1` 运行时错误 · `2` 参数/用法错误。不要用别的码。

`doctor` 默认 `--fail-on error`：发现 Error 级问题 → 退出 1（CI 才有用）。
可用 `--fail-on none|warning|error` 调，`none` 表示永远返回 0。

### 7.5 标准 flag（每个子命令都要有）

`--json` · `--quiet/-q` · `--verbose/-v` · `--no-input` · `--yes/-y` · `--version` · `--project <path>` · `--no-redact`

**AI 不能回答 y/n** —— 所有需要确认的操作必须能被 `--yes` 跳过，且必须有 `--dry-run`。

### 7.6 第一版命令

```bash
uenv scan   --project . [--json] [--out environment.origin.json]
uenv doctor --project . [--json] [--fail-on error]
uenv report --format markdown|json [--out report.md]
uenv fingerprint [--json]
uenv diff <a.json> <b.json> [--json]
```

## 8. 脱敏（默认开启）

报告是要上传的，所以 `--no-redact` 之外一律脱敏：

| 目标 | 替换为 |
|---|---|
| 用户名（`C:\Users\XXX`、`$USERNAME`） | `<user>` |
| 机器名 / 域名 | `<host>` |
| 形如密钥的串（`sk-`、`ghp_`、40+ 位 hex、JWT） | `<redacted>` |
| 代理 URL 里的账号密码 | `<redacted>` |

脱敏发生在 `ScanContext::run/reg_read` 的返回值上，**detector 不需要自己关心**。

## 9. 测试要求

- 每个 detector 至少一个单元测试：给定伪造的 `CommandOutcome`/注册表值，断言解析出的 facts。**为此解析逻辑必须与 IO 分离**（`fn parse(stdout: &str) -> Facts` 独立可测）。
- `uenv-fingerprint` 必须有「同输入两次 → 同 hash」和「改一个字段 → hash 变」的测试。
- `fixtures/env-good.json` + `fixtures/env-broken.json` 用于 diff 集成测试。
- 每完成一项：`cargo fmt --check` → `cargo clippy --workspace --all-targets -- -D warnings` → `cargo test --workspace` 全绿才算完成。
- **禁止声称未经实际运行验证的功能已完成。**
