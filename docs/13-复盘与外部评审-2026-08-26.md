## 三、发布建议（三方合并）

- **仓库名**：gpt 主张 `origin-environment-protocol`（uenv 与 eth-cscs/uenv 撞名）、pi 主张 `uenv`、opus 主张 `u-env`。**建议 `u-env`**：保留 U 系列前缀、避开 HPC 项目的搜索撞车、与二进制名 uenv 一字之差。crates.io 上 `uenv`/`u-env` 目前都未被占（2026-08-26 API 实查）。
- **GO/NO-GO 分层共识**：源码公开 = 有条件 GO（工程诚实度超标）；对外宣传 = NO-GO 直到 ①干净机一跑 ②二进制分发 ③T7 口径修正。crates.io 首发不上（终端 CLI 无 library consumer；等方案 A 有集成者再发 scanner 门面 crate）。
- **README 首屏改造**：下载命令前置（GitHub Release 挂 x64 exe + sha256）→ 30 秒 demo → 非目标声明（只读扫描+建议，不自动执行、不改机器）→ 隐私声明（默认脱敏、零上传）→ 诚实证据（1 台开发机、8 类问题、你的机器结果会不同）→ 支持矩阵 → 协议理念放最后。
- **docs/11 浏览器玩法标着「内部文件（先不开源）」**：公开仓要么移出 docs/ 要么加明确标记。
